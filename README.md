# zs-ui 2.4.0

Expo SDK 58·React Native 0.88용 iOS·Android UI 라이브러리입니다. 컴포넌트, 오버레이, 내비게이션, 색·글꼴 테마와 태블릿·폴더블 레이아웃을 제공합니다.

## 설치

```bash
npx expo install @0610studio/zs-ui@2.4.0
```

추가 의존성과 Provider 설정은 [시작하기](https://0610studio.github.io/zs-ui/docs/Provider/start)를 참고하세요. 네이티브 모듈이 포함되어 개발 빌드가 필요합니다.
