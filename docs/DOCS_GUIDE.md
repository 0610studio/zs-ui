# ZS-ui 문서 작성 기준

공개 컴포넌트 문서는 사용자가 예제를 확인한 뒤 실제 앱 적용 여부를 판단할 수 있도록 아래 순서를 기본으로 사용합니다.

1. 한 문장으로 설명하는 용도
2. `LocalPlayground` 미리보기
3. 네이티브·웹 차이가 있을 때 플랫폼 안내
4. 기본 사용법
5. Props 또는 반환값
6. 상태·variant별 예제
7. 접근성 고려사항
8. 관련 컴포넌트와 다음 문서

## 작성 원칙

- 공개 API 이름과 기본값은 `src/` 타입과 구현을 확인해 작성합니다.
- 내부 렌더러는 직접 사용 여부를 명시합니다.
- 웹 미지원 기능은 플레이그라운드 결과만으로 판단하지 않도록 실제 기기 검증 범위를 적습니다.
- 예제는 한 번에 하나의 개념을 보여주고 복사 가능한 형태로 유지합니다.
- 새 runtime export를 추가하면 `pnpm run validate:coverage`가 통과하도록 관련 문서에 API 이름을 포함합니다.
